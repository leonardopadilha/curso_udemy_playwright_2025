# Playwright ChatGPT

Este projeto contém os exemplos e exercícios desenvolvidos durante o curso.

**Link do Curso:** https://www.udemy.com/course/playwright-2024-avancado-domine-seus-testes/?couponCode=LEARNWITHUSNOW

## Como Executar os Testes

É possível executar os testes de duas formas:

1. **Via package.json**:
   Execute os scripts configurados no arquivo `package.json`, como por exemplo:
   ```bash
   npm test
   ```

2. **Execução Individual**:
   Ao acessar a pasta `tests`, você pode executar os testes de forma individual através do comando:
   ```bash
   npx playwright test <nome-do-arquivo.spec.ts>
   ```
